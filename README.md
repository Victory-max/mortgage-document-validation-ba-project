# Mortgage Document Validation — Business Analyst Practice Project

**Project type:** Fictional training simulation | **Status:** In progress

## Overview
This portfolio documents a simulated mortgage loan application document-validation enhancement. The business problem is incomplete mortgage applications reaching underwriting, creating avoidable rework and delays.

## Objective
Practice requirements elicitation, stakeholder analysis, business and functional requirements, process mapping, Agile delivery, user acceptance testing, and reporting.

## Current deliverables
- `01_Requirements/Mortgage_Document_Validation_BRD_v1_Olubusola_Areo.docx` — Draft Business Requirements Document, version 1.0 (to be uploaded). Proposed requirements and assumptions require validation.

## Planned deliverables (not yet completed)
- `02_Process_Maps/` — current-state and future-state Visio workflows
- `03_Functional_Requirements/` — functional requirements and acceptance criteria
- `04_UAT_and_Analytics/` — Excel traceability, test cases, defect logs, and reporting
- `05_Jira_Artifacts/` — user stories, backlog exports, and screenshots (with no private account information)

## Tools
Microsoft Word, Excel, Visio, and Jira (planned).

## Important note
This is an educational case study, **not** an actual bank implementation or a representation of employment deliverables. All business details are fictional unless explicitly identified otherwise. No customer data is included.
